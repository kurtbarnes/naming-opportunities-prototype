# Naming Opportunities Prototype

An interactive HTML/CSS/JS prototype replicating the layout and interactions of the AppsNXT Naming Opportunities list screen (as embedded in Raiser's Edge NXT), built as a base for iterating on UI/UX changes without touching the live app.

Static, self-contained — no build step, no backend. Sample data is generated client-side and is entirely fictional.

## Features replicated
- Header, side nav, and RE NXT-style page chrome
- Tab strip (Admin Settings / Naming Opportunity List / Instance List / Dashboard)
- Toolbar: new record, search, include-inactive, filter, export, reset, column picker
- Sortable, searchable, paginated data table with status pills
- Slide-in drawer for creating/editing a naming opportunity

## Run locally
Just open `index.html` in a browser — no server required.
